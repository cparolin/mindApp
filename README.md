# Conscist 🧠✨

### Uniting weekly organization and emotional well-being in one place. 📅

**Conscist** is a native iOS application born from the idea of making two things that make a huge difference in your routine more accessible: intuitive visual weekly planning and mental health care through Cognitive Behavioral Therapy (CBT).

## 📖 About

**Conscist** bridges the gap between structured lifestyle management and emotional self-care. By integrating the **Dysfunctional Thoughts Record (DTR)** technique — one of CBT's most effective tools — the app helps users identify triggers, structure thoughts, and foster emotional well-being over time. 

The app is **live on the App Store**! [Download it here](https://lnkd.in/dFcCabua). If you want to explore the design journey, research, and visual decisions behind the interface, check out the [Behance Case Study](https://lnkd.in/d8B2n3Pi).

## 🚀 Features

- **📅 Weekly Organization** — A visual calendar featuring tasks and events classified by colors, representative symbols, and a fully customizable layout.
- **📓 Thought Journal with DTR** — Thematic journals with guiding questions that help structure entries, identify challenges, and promote emotional well-being over time.
- **🔔 Smart Reminders** — Native iOS notifications to keep you aligned with your weekly goals.
- **🔒 Privacy First** — Built with data security and local privacy in mind.

## 🎨 Design Process

The entire application design was carefully crafted from initial research to final visual decisions. This journey included multiple rounds of testing with real users, which were essential to refine the experience and ensure the app felt genuinely welcoming, intuitive, and safe. You can check out the full visual breakdown on [Behance](https://lnkd.in/d8B2n3Pi).

## 🛠️ Tech Stack

This project is built using modern Apple frameworks to ensure high performance and a smooth user experience:

| Technology | Purpose |
|------------|---------|
| **Swift & SwiftUI** | Declarative UI framework for building smooth, responsive, and adaptive interfaces. |
| **SwiftData** | Modern persistence framework used to store tasks, journals, and preferences locally. |
| **UserNotifications** | Scheduling and managing local daily reminders. |
| **MVVM Architecture** | Ensures a clean separation of concerns between views and business logic. |
